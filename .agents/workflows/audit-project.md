---
description: Audit the repository before implementation
---

1. Act as `@architect`, `@qa`, and `@security`.
2. Read `README.md`, `TASKS.md`, `DECISIONS.md`, `SECURITY.md`, and the files relevant to the current phase.
3. Inspect the current code and tests.
4. Produce `artifacts/AUDIT_REPORT.md` with:
   - Current phase
   - Completed items
   - Missing items
   - Data-loss risks
   - Duplicate risks
   - Security risks
   - Recommended next task
5. Do not change production code during this workflow.
